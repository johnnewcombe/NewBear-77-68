Altair 680 BASIC - Microsoft's first product!

The file Altair_BASIC_7768.S19 is patched for the 77-68 system with an ACIA at 8000H. Patch source is included, as is a patch .s19 file and the original tape file.

The patch I have included is a clone of the 680 Monitor ROM vs. other popular patches out there. It correctly passes characters in Acc B vs. Acc A.
 
To launch type J 0000.

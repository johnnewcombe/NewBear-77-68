# Ouput Messages


All valid weight messages include the following messages in the order specified.

1. Greeting message (waiting for the weight to settle)
1. The weight message itself.
1. Comment.

If no weight data is received for a preset period e.g. no one is using the scales, an Idle message is output.

The comment will be picked from one of four groups depending upon weight. The groups are

* Light Wight
* Mormal Weight
* Heavy Weight
* Super Heavy Weight
